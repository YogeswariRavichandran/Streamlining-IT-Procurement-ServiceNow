# Phase 5 – Project Development

## Development Platform

The project is developed using the ServiceNow platform.

## 1. Service Catalog

A Service Catalog item is created for submitting IT procurement
requests.

The catalog item collects the required information from the requester.

## 2. Request Submission

The requester enters the required procurement information and submits
the request.

## 3. Flow Designer

Flow Designer is used to automate the procurement process.

## 4. Automated Workflow

The workflow performs the following activities:

1. Detects the submitted procurement request.
2. Processes the request information.
3. Sends the request for approval.
4. Waits for the approval result.
5. Processes the approval decision.
6. Creates procurement-related tasks after approval.
7. Updates the request status.
8. Sends notifications when required.

## 5. Approval Process

If the request is approved, the workflow continues with procurement
processing.

If the request is rejected, the request is updated accordingly.

## 6. Task Creation

Approved requests result in the creation of tasks for the responsible
IT or procurement team.

## 7. Final Process

Request
→ Approval
→ Task Creation
→ Procurement Processing
→ Completion

## Development Result

The IT procurement workflow is automated using ServiceNow Flow
Designer, reducing the need for manual coordination and task creation.
