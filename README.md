# Streamlining IT Procurement using ServiceNow

## Project Description

This project automates the IT procurement process using ServiceNow.

## Problem

Traditional IT procurement requires manual request handling,
coordination and task creation, which can cause delays.

## Solution

ServiceNow Service Catalog and Flow Designer are used to automate
request submission, approval, task creation, notifications and
request tracking.

## Technologies

- ServiceNow
- Service Catalog
- Flow Designer

## Project Phases

1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

## Workflow

User Request
→ Approval
→ Automated Task Creation
→ Procurement Processing
→ Completion
