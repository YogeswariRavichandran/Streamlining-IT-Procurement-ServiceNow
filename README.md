# Streamlining IT Procurement using ServiceNow

## Project Description

This project automates the IT procurement process using ServiceNow.

## Problem

Traditional IT procurement requires manual request handling,
coordination and task creation, which can cause delays.

## Solution

ServiceNow Service Catalog and Flow Designer are used to automate
request submission, approval, task creation, notifications and
request tracking.

## Technologies

- ServiceNow
- Service Catalog
- Flow Designer
