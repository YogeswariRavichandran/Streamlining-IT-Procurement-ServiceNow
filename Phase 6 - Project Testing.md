# Phase 6 – Project Testing

## Testing Objective

The objective of testing is to verify that the IT procurement workflow
works correctly from request submission to completion.

## Test Cases

| Test Case | Expected Result | Status |
|---|---|---|
| Submit procurement request | Request should be created | Pass |
| Enter required information | Information should be accepted | Pass |
| Trigger workflow | Flow should execute | Pass |
| Send approval | Approval should be generated | Pass |
| Approve request | Workflow should continue | Pass |
| Reject request | Request should be rejected/updated | Pass |
| Create procurement task | Task should be created | Pass |
| Update request status | Status should change correctly | Pass |
| Send notification | Notification should be generated | Pass |
| Complete task | Request should reach completion | Pass |

## Testing Result

The major workflow functions were tested to verify request submission,
approval, automated task creation, status updates and completion.

## Conclusion

The testing confirms that the proposed automated IT procurement
workflow performs the expected process under the tested scenarios.
